---

## Descripción General

CachiMP3 es una aplicación Flutter que permite a los usuarios descargar videos y convertirlos a archivos de audio MP3. Fue desarrollada como proyecto de aprendizaje para explorar el desarrollo multiplataforma con Flutter.

La aplicación soporta múltiples plataformas incluyendo Android, iOS, web, Linux y macOS. Actualmente se encuentra en fase inicial de desarrollo.
